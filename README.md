# Мой английский

> 📚 Мобильное приложение для изучения английских слов с помощью профилей, групп, карточек и интервального повторения.

Приложение помогает создавать собственные словари, изучать слова с помощью карточек, отслеживать прогресс и управлять данными полностью локально — без сервера и облачной синхронизации.

---

## ✨ Возможности

### 👤 Профили

- создание нескольких профилей пользователей;
- переключение между профилями;
- отдельный словарь и прогресс для каждого профиля;
- редактирование и удаление профилей;
- подтверждение перед удалением.

### 📖 Работа со словами

- добавление слов вручную;
- редактирование существующих слов;
- удаление слов;
- поиск по английскому слову и переводу;
- фильтрация по статусу;
- массовое управление словами;
- объединение слов в группы;
- массовый ввод нескольких слов.

### 📝 Массовый ввод

Поддерживаются следующие разделители:

| Разделитель | Пример |
|---|---|
| `-` | `apple - яблоко` |
| `=` | `apple = яблоко` |
| `:` | `apple : яблоко` |
| `\|` | `apple \| яблоко` |

Пример:

```text
apple - яблоко
book - книга
run - бегать
```

---

## 🎴 Обучение

Доступны несколько режимов обучения:

- 📚 все слова;
- 🆕 новые слова;
- 🔄 слова на повторение;
- ✅ запомненные слова.

Во время обучения слово можно отметить как:

- **Запомнено**
- **Повторить**

Также доступны карточки с переворотом для удобного запоминания слов.

---

## 📊 Статистика

Для каждого профиля отображается:

- общее количество слов;
- количество новых слов;
- количество слов на повторение;
- количество запомненных слов;
- общий процент прогресса.

Прогресс рассчитывается отдельно для активного профиля.

---

## 🔎 Поиск и фильтрация

На экране слов доступны:

- поиск по английскому слову;
- поиск по переводу;
- фильтр всех слов;
- фильтр новых слов;
- фильтр слов на повторение;
- фильтр запомненных слов.

## 📥 Импорт

Приложение поддерживает импорт слов из:

- `.txt`
- `.csv`
- `.json`

### TXT

Одна пара на строку:

```text
apple - яблоко
book - книга
run - бегать
```

### CSV

Минимальный формат:

```csv
english,russian,group
hello,привет,Базовые слова
apple,яблоко,Еда
```

Колонки:

- `english` — обязательная;
- `russian` — обязательная;
- `group` — необязательная.

При импорте:

- дубликаты пропускаются;
- существующие слова не удаляются;
- новые слова добавляются в текущий профиль.

## 📤 Экспорт и резервное копирование

Поддерживаются:

### CSV

Экспорт слов в CSV для дальнейшего использования или обработки.

### JSON

Полный экспорт данных приложения:

- профили;
- группы;
- слова;
- настройки;
- прогресс.

JSON можно использовать как полную резервную копию.

При восстановлении JSON текущие данные заменяются данными из файла.

> 🛡️ Перед восстановлением автоматически создаётся локальная резервная копия текущих данных.

Также доступно восстановление последней локальной резервной копии.
