# Мой английский

Мобильное приложение для изучения английских слов с помощью профилей, групп и карточек.

## Возможности

- создание нескольких профилей пользователей;
- добавление, редактирование и удаление слов;
- объединение слов в группы;
- массовый ввод слов;
- выбор разделителя для массового ввода: `-`, `=`, `:` или `|`;
- режимы обучения по всем словам, новым словам и словам на повторение;
- отметка слова как запомненного или требующего повторения;
- карточки с переворотом;
- статистика прогресса профиля;
- светлая и темная тема;
- поиск, фильтрация и массовое управление словами;
- импорт слов из CSV и TXT;
- экспорт слов в CSV;
- полный экспорт и восстановление данных через JSON;
- автоматическая локальная резервная копия перед сохранением данных;
- восстановление последней локальной копии;
- подтверждение перед удалением профилей, групп, слов и всех данных.

## Хранение данных

Приложение работает локально. Профили, слова, группы, настройки и прогресс хранятся на устройстве через `AsyncStorage`.

Облачной синхронизации, API и серверной базы данных в приложении нет.

## Массовый ввод

Откройте **Слова → Добавить → Несколько слов**.

Каждая строка должна содержать английское слово, разделитель и перевод:

```text
apple - яблоко
book - книга
run - бегать
```

По умолчанию используется дефис. Также доступны `=`, `:` и `|`.

## Импорт файлов

### TXT

Обычный текстовый файл должен содержать одну пару на строку:

```text
apple - яблоко
book - книга
run - бегать
```

### CSV

Минимальный формат CSV:

```csv
english,russian,group
hello,привет,Базовые слова
apple,яблоко,Еда
```

Колонки `english` и `russian` обязательны, `group` необязательна. Дубли при импорте пропускаются, существующие слова не удаляются.

### JSON

JSON используется для полного резервного копирования. При восстановлении JSON текущие профили, группы, слова, настройки и прогресс заменяются данными из файла. Перед заменой текущая версия сохраняется в локальную резервную копию.

## Запуск проекта

Требуется Node.js и npm.

```powershell
npm install
npm start
```

Доступные команды:

```powershell
npm run android
npm run web
npx expo start --clear
```

Для web-версии откройте адрес, который покажет Expo, обычно:

```text
http://localhost:8081
```

## Сборка APK

Для облачной сборки нужен аккаунт Expo/EAS:

```powershell
npx eas-cli login
npm run build:apk
```

Профиль `preview` создает установочный APK. После завершения EAS покажет ссылку на скачивание файла.

Для локальной Android-сборки дополнительно нужны Android Studio, Android SDK и JDK 17:

```powershell
npx expo prebuild
npx expo run:android --variant release
```

## Структура проекта

- `App.tsx` — точка входа приложения;
- `src/context` — состояние и операции с данными;
- `src/screens` — экраны приложения;
- `src/components` — переиспользуемые компоненты;
- `src/navigation` — навигация;
- `src/storage` — локальное хранение и импорт/экспорт;
- `src/theme` — светлая и темная темы;
- `assets` — изображения и иконки.
